# Release notes for v0.2.24 (GitHub release copy, sourced from the in-app What's-new panel)

**Voice alerts, unlocked for Linux — one switch, 28 voices, and an honest name.** *(Release notes in the app's own words, which are also the owner's words.)*

**New — Alerts can talk on Linux now.** The Voice section of Preferences lists your system's built-in voices with nothing to install - the same voices your desktop's accessibility layer already uses. Fair warning: on most distributions they sound a bit robotic.

**New — Want a voice worth listening to?** The "Natural voice (downloaded)" tier fetches the Kokoro voice package - one click, about 115 MB, offline from then on - and adds 28 English voices to the picker (US and British, female and male). Pick the one your alerts speak with; every alert can use it.

**Changed — The built-in voice tier is now called "System voices (built in)"** - it used to be labeled "Windows voices", which was never the whole truth on Linux.

---

**Install:** download the AppImage below, make it executable (`chmod +x "Brujoloco.EQL.Companion-0.2.24.AppImage"`) and run it. The host needs **FUSE** for AppImage execution. Point the app at your EverQuest install under a Wine prefix via Settings and it reads the same log it always has.

*Brujoloco EQL Companion, Linux Edition — a private fork of EQ Zera (upstream FSL-1.1-MIT; Linux Edition additions MIT). Update checks are disabled in this build.*
