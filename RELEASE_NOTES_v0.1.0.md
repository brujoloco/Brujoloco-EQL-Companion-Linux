# Brujoloco EQL Companion 0.1.0 — Linux Edition

**Build date:** October 19, 2026

First release. A full rework of the EQ Zera 1.26.1 build into a native Linux AppImage.

- **New** — Brujoloco EQL Companion, Linux Edition — a full rework of the EQ Zera 1.26.1 build into a native Linux AppImage. The Rust log engine (zengine) is compiled natively for linux-x64 and bundled inside the AppImage; the Electron renderer and main bundles build clean on Linux with no source changes. Point the app at your EverQuest install under a Wine prefix via Settings and it reads the same log it has always read.
- **New** — Runtime theme system: a Preferences → Appearance → Theme picker with 36 palettes, all switchable live with no restart. The palette module was converted to a live-binding reassignment so all 70 consuming files pick up the new tokens without a rewrite, and the MUI theme is rebuilt on every swap through a makeTheme(palette) factory plus a useSyncExternalStore version counter.
- **New** — 36 themes ship in this build: the default Arcane (byte-identical to the original EQ Zera palette), Parchment & Gold (the upstream jmoyers brownish look), CRT Green/Amber/Orange, Monochrome, Paper White, the three Windows 95 greys, Synthwave 80s, Cyberpunk, Vaporwave, Retrofuturistic, Vintage Sepia, Vintage Cream, Solarized Dark/Light, Dracula, Nord, Gruvbox, Tokyo Night, Catppuccin Mocha, One Dark, six Brujoloco dark CRT / retro-80s / cyberpunk green-on-black themes, and six BrujoGnome high-contrast pastel themes.
- **Fixed** — Adaptive light/dark mode: the MUI theme was hardcoded to dark mode, so the six light themes (Paper White, the three Windows 95 greys, Vintage Cream, Solarized Light) rendered invisible light-on-light text in every submenu. The mode is now derived from each palette — text lighter than paper is dark, text darker than paper is light — so the Preferences rail, dropdowns and cards all flip to readable dark text on light themes.
- **Fixed** — The page body background, the 28px grid, ::selection and the scrollbar thumb were module-scope constants that captured the default dark palette at import time and never rebuilt, so the window background stayed the original dark navy on every theme. They are now functions of the live palette, so a theme swap recolours the whole page — the root cause of the "the background is always the original dark blue background" report.
- **Fixed** — Mode-aware scrollbar: the thumb is a white tint on dark themes and a black tint on light themes, so scrollbars stay visible on the light themes' light scroll surfaces instead of disappearing.
- **Fixed** — Every cataloged theme is verified to clear WCAG AA (≥4.5:1) for body text on background and paper, and for the accent on paper — enforced by a new themes.test.mts suite that fails the build if a theme ships unreadable. Single-hue themes allow the accent to repeat a series colour; the four non-accent series tokens (cyan/green/amber/red) stay pairwise distinct so charts never draw two lanes in one colour.
- **Changed** — In-app and OS rebrand to "Brujoloco EQL Companion": the OS window title, the tray menu and tooltip, the HTML <title>, the electron-builder appId/productName, and the in-app title-bar wordmark all carry the new name.
- **Changed** — Update checks and the Send feedback surface are disabled in this build: the upstream EQ Zera release feed and feedback endpoint are not compatible with the Linux Edition, so the updater is short-circuited (no network call) and both the Preferences and nav-drawer feedback entry points are no-ops with an honest "disabled in this build" note. Both are reversible by flipping one flag / restoring the onClick handlers.
- **New** — The floating overlays now follow the main theme. Every overlay window (zone meter, fight meter, fight healing, zone healing, event log, buffs, debuffs, xp, respawn, farm meter, run tracker, mob card on /con) is its own renderer process, so it kept the default bluish palette no matter which theme the main window was in. The theme now rides onto them: the overlay preload exposes themeGet + onTheme, the main process broadcasts the theme id to every open overlay on a change and seeds a late-opened one on mount, and the overlay root is wrapped in the app’s MUI ThemeProvider so a live swap recolours it. The overlay components’ module-scope colour captures were converted to live PALETTE reads, and the opaque overlays’ native background is read live too — so a theme change recolours every overlay, with no restart.
- **New** — Preferences → About this build: a new section directly above Thanks, naming the build and its origin, declaring it final for Linux, and disclosing the open license — upstream code under FSL-1.1-MIT, the Brujoloco Linux Edition additions under MIT.

---

**Install:** Download `Brujoloco EQL Companion-0.1.0.AppImage` below, make it executable (`chmod +x`), and run it. On Ubuntu 24.04 install FUSE first (`sudo apt-get install libfuse2t64`), or run with `--appimage-extract-and-run` if FUSE is unavailable.
